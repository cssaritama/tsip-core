# Roadmap

| Release | Scope |
|---|---|
| **0.1** (current) | S&P 500 and Bitcoin; level memory, sessions, weekly structure, paths, entries, calendar; evidence grades; daily report; hypothesis register. |
| 0.2 | Rolling 6/12/18/24/25-hour windows; Monday range studies; prior-quarter and prior-year levels; session break-and-hold studies; Spanish edition of the site. |
| 0.3 | Predictive track: a unified feature table of time–space coordinates, gradient-boosted and linear models for forward returns, and strategy simulation against total-return benchmarks. Every model is evaluated with the same evidence rules. |
| 0.4 | Nasdaq-100 (NDX, QQQ); index futures sessions (ES, NQ) once a suitable data feed is in place. |
| 0.5 | Bitcoin on-chain cohorts: cost basis of large holders, exchange flows, each published as a hypothesis with its own grade. |
| 0.6 | Insider purchase clusters (SEC Form 4) and institutional holdings (13F, 45-day lag disclosed), with tests of copy strategies after the real reporting delay. |
| 0.7 | Statistics API and machine-readable feeds for research agents. |

Items move only when the previous release's statistics are reproducible from a clean checkout.
